## 2. Deskripsi Sistem
Sistem ini memodelkan arsitektur perangkat Internet of Things (IoT) pada ekosistem *Smart Greenhouse* menggunakan bahasa pemrograman Java. Sistem mencakup manajemen koneksi jaringan berbasis LoRaWAN, kalibrasi sensor, serta evaluasi otomatis kondisi lingkungan (kelembapan tanah dan suhu udara) untuk mengendalikan aktuator irigasi dan kipas pendingin.
